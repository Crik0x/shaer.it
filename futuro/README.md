# futuro/ — il parcheggio delle idee di metodo

> **Cos'è.** Lavoro **futuro sul metodo e sugli strumenti** (agenti, automazioni,
> migliorie di processo) che **non** è task di prodotto e **non** deve appesantire
> `memoria/TODO.md`. Il TODO è il saldo dei task che costruiscono Shaer.it; questa
> cartella tiene ciò che costruisce *il modo* in cui li costruiamo.
>
> Regola: qui si **accumula senza tetto** (come la resa, `lavoro.md §10-bis`), costa
> zero contesto perché non è auto-caricato. Nulla si cancella: quando un'idea si
> realizza, il suo file si sposta in `futuro/fatto/` con la data.

## Come si aggiunge un'idea

Un file per idea, con: **cosa** fa, **perché** serve, **quando** conviene farlo, e
un **piano già pronto** (come le `[N]` del TODO: chi legge deve poter partire senza
altro contesto). Poi una riga qui nell'indice.
